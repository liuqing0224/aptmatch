# 用 Codex 给简历「把把脉」：个人简历 × 公司契合度匹配工具

> 投简历之前，先让 AI 帮你评估一下：这份 JD 我到底合不合适？这家公司值不值得去？
> 这个工具（AptMatch / 适所）就是干这个的——把简历和岗位描述交给本地运行的 AI 助手（Codex），
> 它会联网查公司官网、招聘页、财报，然后给你一份带分数的契合度报告。

**项目开源地址：[https://github.com/liuqing0224/aptmatch](https://github.com/liuqing0224/aptmatch)**

---

## 一、它能帮你做什么

- **判断合不合适**：简历和 JD 硬性要求差多远、技能重合度有多高，给一个 0–100 的总分和 S/A/B/C/D 等级。
- **判断公司靠不靠谱**：AI 会去查公司官网、招聘信息、业绩新闻，还会比对社区「企业黑名单」，避免踩坑。
- **告诉你该怎么准备**：列出差距、风险、面试时该问的问题、简历里应该突出的优势。

## 二、谁适合用这个工具？

- **应届生 / 转行者**：不知道自己的简历能投什么岗位，让 AI 按 JD 逐条帮你比对，快速圈定方向。
- **跳槽者**：遇到心仪岗位或 offer，先做一次「入职前体检」——契合度、公司经营风险、该确认的问题一次说清。
- **海投党**：投了几十家没回音？先批量筛掉明显不匹配的岗位，把精力集中在真正有戏的目标上。
- **谨慎派**：投简历前先搜企业黑名单、看 AI 联网调研的公司新闻与财报，避开坑。

一句话：**只要你在找工作，或帮朋友看机会，它都能当你的「投递前参谋」。**

## 三、为什么是 AptMatch

| 对比项 | 海投 + 肉眼比对 | 通用 AI 聊天 | AptMatch（适所） |
| --- | --- | --- | --- |
| 匹配判断 | 凭感觉，容易漏硬性要求 | 单轮问答，不逐条对照 | 10 个维度打分，逐条附原文证据 |
| 公司调研 | 基本不查 | 一般不联网核实 | 自动查官网、招聘页、新闻、财报 |
| 隐私保护 | 简历散布各平台 | 简历可能被用于训练 | 数据 100% 在本机，不出本机 |
| 批量场景 | 一份份手动看 | 不适合批量 | 批量爬取岗位 + 排队分析 |
| 成本 | 时间成本高 | 会员 / 次数限制 | 开源免费，本地运行 |

几个你可能关心的点：

- **隐私优先**：所有简历、报告只存在你自己电脑的 `.data/` 目录，不上传云端；
- **可解释**：每个分数都有「为什么」，引用简历原文和 JD 原文，不是黑箱；
- **会联网做功课**：官网、招聘页、财报、社区黑名单，AI 主动帮你查；
- **越用越准**：Agent 会把每次分析沉淀为经验，下次分析更贴近你的偏好；
- **开源可改**：全代码开源，欢迎按自己的流程改造成「你的求职系统」。

## 四、安装与启动（大约 3 分钟）

工具跑在你自己电脑上，数据不出本机。

```bash
# 1. 进入项目目录，安装依赖
cd /Users/l/Documents/ChatGPT/招聘
npm install

# 2. 一键启动（后端 + 前端同时运行）
npm run dev
```

然后打开浏览器访问 **http://127.0.0.1:5173** 就能用了。

第一次使用前，确认电脑上装了 Codex 命令行工具（`codex`），它负责真正跑分析任务。

## 五、5 分钟跑通第一次匹配

### 第 1 步：录入简历

打开左侧「**简历与公司**」，把简历粘贴进去，或者直接上传 PDF / DOCX 文件。

### 第 2 步：添加目标公司

在同一页面添加公司，填上公司名、粘贴岗位描述（JD），再贴一个公司官网链接（方便 AI 调研）。

> 如果手头没有具体目标公司，先跳过这步，看下面的「没有目标公司怎么办」。

### 第 3 步：派发匹配任务

打开「**新建匹配**」：

1. 选择简历；
2. 选择目标公司（也可以不选，见下文）；
3. 选一个 Agent（默认 Codex 就行）；
4. 点击「开始分析」。

任务会进入「**看板**」，一般几分钟到 10 分钟内完成（AI 要联网查资料、读简历、写报告）。

### 第 4 步：读报告

点开任务就能看到完整报告：

- **总分 + 等级**，一眼知道该不该投；
- **雷达图**：硬技能、经验、岗位职责、薪资、文化、稳定性等 10 个维度的得分；
- **匹配要点 / 差距与弥补**：哪里对口、哪里不足、怎么补；
- **面试问题**：建议向公司确认的事情；
- **调研来源**：AI 参考过的官网、招聘页链接，可以点进去核实。

![契合度报告](/Users/l/Documents/ChatGPT/招聘/docs/screenshots/01-report-full.png)

看完报告，还可以点击「导出 Markdown」存成文件，或者直接「追问」——比如「帮我把差距部分展开，给出补课计划」。

## 六、没有目标公司怎么办？让 AI 先帮你找岗位（方案 B）

很多求职者是「先看有什么岗位，再挑公司」。这时用「**批量爬取并匹配**」：

1. 在「新建匹配」里选「批量爬取」，填**岗位关键词**（比如「高级数据工程师」）和**城市**；
2. AI 会去 BOSS 直聘、公司官网等公开渠道抓取真实的岗位 JD；
3. 抓回来后，勾选你感兴趣的岗位，一键导入公司库；
4. 自动批量派发契合度分析，所有公司一起评分。

![新建匹配](/Users/l/Documents/ChatGPT/招聘/docs/screenshots/03-new-match.png)

之后到「**对比**」页面，同一份简历对多家公司的得分横向排序，一眼看清哪家最值得投。

![对比](/Users/l/Documents/ChatGPT/招聘/docs/screenshots/04-compare.png)

## 八、实际效果：两个真实例子

**例子一：候选人 A（Android 开发，2 年经验）→ 中科创达 Android Framework 岗**

总分 **57 分（B 级）**。报告的结论是：

> Android 应用层功底扎实、性能与鸿蒙经验亮眼，但 Framework 系统层经验为零，属跨层转岗，需补齐系统知识并谨慎权衡。

- 匹配的点：Java、UI 渲染机制、性能优化（BML 耗时 -220ms）、鸿蒙适配——正好对上公司 OpenHarmony 生态；
- 拉分的地方：JD 硬性要求「2 年以上 Framework 经验」和 AMS/WMS 系统服务，简历零证据；
- AI 调研了 8 个来源（猎聘岗位页、牛客网、公司 2026 新年致辞等）。

**例子二：同一份简历（候选人 A）→ 元征科技（汽车诊断硬件公司，港股上市）**

总分 **63 分（B 级）**。AI 联网核验了官网、猎聘 JD 原文和公司年报（营收 21.1 亿、海外占比 73%），给出建议：**「C 端 Android 功底扎实，但端侧 AI 部署经验与 3-5 年年限差距明显，先确认门槛弹性再投」**。

两个例子说明：它不会无脑给高分，而是诚实地告诉你差距在哪、值不值得投、投之前要确认什么。

## 九、常见问题

**问：AI 给出的分数靠谱吗？**
答：分数是 AI 基于简历与 JD 的语义分析，会联网核实公司信息。它更适合当「决策参考」——帮你筛掉明显不合适的、抓住重点去准备，而不是替你决定。

**问：收费吗？**
答：完全免费。工具本身开源，运行只依赖本机已有的 Codex CLI（同样是免费开源工具），没有会员、没有次数限制。

**问：需要联网吗？**
答：分析过程需要联网（查公司资料）。如果网络不好，AI 会在报告里注明「调研受限」，但主分析不中断。

**问：数据安全吗？**
答：所有数据都保存在你自己电脑的 `.data/` 目录，不上传任何云端；只有分析任务需要 AI 联网查公开资料。

**问：一次可以分析几家公司？**
答：批量模式下可以一次勾选多个岗位/公司，同时排队分析；并发数可以在设置里调（默认 1，避免电脑太忙）。
